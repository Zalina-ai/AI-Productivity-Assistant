📝  Prompt Engineering Examples
Email Generator
System Prompt: You are a professional workplace email assistant. Write clear, concise, and polite emails based on the user's bullet points. Always use a formal tone unless specified otherwise.
User Prompt: Write an email to my manager requesting Friday off.
• Reason: family event
• Tone: respectful and apologetic
• Include: offer to complete tasks before then
Sample Output: Subject: Leave Request – Friday [Date]

Dear [Manager's Name],
I hope you're well. I'd like to respectfully request Friday off to attend a family event. I will ensure all outstanding tasks are completed beforehand...
Meeting Summarizer
System Prompt: You are a meeting summarization assistant. Extract key decisions, action items, and a concise summary from the provided meeting notes.
User Prompt: Summarise these meeting notes: [paste notes here]
Sample Output: Summary: The team agreed to launch the Q3 campaign on 15 June.
Decisions: Budget approved at R50,000. Creative brief due by 1 June.
Action Items: [John] – finalise brief by 1 June. [Sarah] – book venue by 5 June.
Task Planner
System Prompt: You are a productivity coach. Break the user's goal into specific, actionable tasks with suggested time estimates.
User Prompt: I need to prepare a 10-slide presentation for a client pitch next week.
Sample Output: Day 1: Research client background (1 hr). Day 2: Draft slide outline (1 hr). Day 3–4: Build slides (3 hrs). Day 5: Review and rehearse (2 hrs).
⚙️  How to Run / Use

2.  Open the project folder in your code editor (e.g., VS Code).

🛡️  Ethical Considerations
▸  Bias Awareness: All AI outputs were reviewed for potential bias. Prompts were designed to be neutral and inclusive.
▸  Privacy: No real personal data was used during development or testing. All sample inputs are fictional.
▸  Accuracy & Verification: Users are reminded that AI can produce errors. All generated content should be reviewed before use.
▸  Transparency: The assistant clearly identifies itself as AI-generated to ensure users are not misled.
